# Instruções para Criar um Pull Request (PR) no GitHub

## Passo a passo

1. **Acesse o repositório no GitHub**
   - Entre no seu repositório pelo navegador.

2. **Selecione a branch**
   - No topo da página, clique no seletor de branch e escolha a branch criada (ex: `refactor/estrutura-moderna`).

3. **Clique em “Compare & pull request”**
   - O GitHub geralmente mostra um botão verde “Compare & pull request” assim que você faz push de uma branch nova. Clique nele.

4. **Preencha o título e a descrição**
   - **Título:** Refatoração estrutural do sistema (ou algo descritivo)
   - **Descrição:** Explique as principais mudanças, motivos da refatoração, pontos de atenção, etc. Você pode copiar o texto do README ou do sumário do projeto.

5. **Escolha a base e a branch de comparação**
   - **base:** `master` ou `main` (branch principal)
   - **compare:** `refactor/estrutura-moderna` (sua branch)

6. **Clique em “Create pull request”**
   - O PR será criado e ficará disponível para revisão, comentários e merge futuro.

---

## Dicas

- Se desejar, adicione revisores ou marcadores (labels) ao PR.
- Use o README.md da branch para detalhar as mudanças.
- Após aprovação, o merge pode ser feito pelo responsável do repositório.
